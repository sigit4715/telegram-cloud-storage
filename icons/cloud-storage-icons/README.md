# Cloud Storage SVG Icon Pack

Paket ini berisi ikon SVG siap pakai yang mengikuti gaya dashboard pada gambar.

## Isi
- SVG individual
- `sprite.svg`
- `icons.css`
- `preview.html`

## Pakai SVG langsung
```html
<img src="/icons/folder-card.svg" width="24" height="24" alt="Folder">
<img src="/icons/pdf.svg" width="24" height="24" alt="PDF">
```

## Pakai sprite
```html
<svg class="svg-icon"><use href="/icons/sprite.svg#icon-dashboard"></use></svg>
<svg class="svg-icon"><use href="/icons/sprite.svg#icon-upload"></use></svg>
```
